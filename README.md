Open Source Graphing calculator

Based on  JSXGraph, Nerdamer and MathQuill.

Features:
* Intuitive graphical expression editing via MathQuill
* Plot functions and implicit curves like ellipses, circles, hyperbolas and much more!
* Quickly share a graph via a link, all of the information of the graph is stored in the link itself
